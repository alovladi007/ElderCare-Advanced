# Personal AI Companion for Elderly Patients

## Overview

A caring, intelligent AI companion designed specifically for elderly patients. Like having a friendly caregiver available 24/7 for conversations, daily task reminders, emotional support, and practical assistance.

**Key Features:**
- 💬 **Natural Conversations** - Chat like talking to a friend
- 🤖 **AI-Powered** - Uses GPT-4/GPT-3.5 for intelligent responses
- 💊 **Medication Reminders** - Never forget to take medicine
- 📅 **Appointment Tracking** - Stay on top of doctor visits
- 📞 **Family Connection** - Easy way to reach loved ones
- 💪 **Exercise Motivation** - Gentle encouragement for activity
- ❤️ **Emotional Support** - Always there to listen and care
- 🧠 **Memory** - Remembers past conversations and preferences

## Safety & Privacy

### What AI Companion CANNOT Do

**Medical Limitations:**
- ❌ Cannot diagnose illnesses
- ❌ Cannot prescribe medications
- ❌ Cannot change medication dosages
- ❌ Cannot provide emergency medical care

**Always Refers to Professionals:**
- "That sounds concerning - please call your doctor"
- "I'm not qualified to advise on that - let's contact your healthcare provider"
- "For medical issues, we should reach out to your nurse"

### Emergency Handling

**Recognizes Emergencies:**
- "I'm having chest pain" → Immediately advises calling 911
- "I fell and can't get up" → Triggers emergency alert
- "I can't breathe" → Emergency protocol activated

**Never Delays Help:**
- Prioritizes safety over conversation
- Directs to immediate assistance
- Notifies family and emergency services

### Privacy Protection

**What's Stored:**
- ✅ Conversation transcripts (text only)
- ✅ Timestamps
- ✅ Actions triggered
- ✅ Mood assessments

**What's NOT Stored:**
- ❌ Audio recordings
- ❌ Personal financial information
- ❌ Passwords or access codes
- ❌ Medical diagnoses

**Data Security:**
- Encrypted conversations
- HIPAA-compliant storage
- Access controlled by user
- Can delete history anytime

## API Integration

### Backend Endpoints

**Chat:**
```bash
POST /api/ai-companion/chat
Body: {
  "elderId": "elder-123",
  "message": "Good morning, how are you?"
}

Response: {
  "response": "Good morning, John! I'm doing well, thank you. How are you feeling today?",
  "companionName": "Emma",
  "actions": [
    {
      "type": "MEDICATION_REMINDER",
      "data": {...}
    }
  ]
}
```

**Get Conversation History:**
```bash
GET /api/ai-companion/conversation/:elderId?limit=50

Response: [
  {
    "role": "user",
    "content": "Good morning",
    "timestamp": "2026-05-17T08:00:00Z"
  },
  {
    "role": "assistant",
    "content": "Good morning! How did you sleep?",
    "timestamp": "2026-05-17T08:00:01Z"
  }
]
```

**Get Statistics:**
```bash
GET /api/ai-companion/stats/:elderId?days=7

Response: {
  "totalConversations": 24,
  "averagePerDay": 3.4,
  "lastConversation": "2026-05-17T10:30:00Z"
}
```

**Send Proactive Reminder:**
```bash
POST /api/ai-companion/reminder
Body: {
  "elderId": "elder-123",
  "type": "MEDICATION",
  "data": {
    "medicationName": "Lisinopril",
    "dosage": "10mg"
  }
}
```

## Database Schema

### CompanionSettings
```sql
elderId              UUID (unique)
enabled              BOOLEAN
personalityName      STRING      -- "Emma", "Michael", etc.
personalityTraits    JSON        -- Array of traits
voiceEnabled         BOOLEAN     -- Text-to-speech on/off
proactiveReminders   BOOLEAN     -- Auto reminders
emotionalSupport     BOOLEAN     -- Companionship mode
medicationReminders  BOOLEAN
appointmentReminders BOOLEAN
exerciseReminders    BOOLEAN
checkInFrequency     STRING      -- daily, twice_daily, weekly
responseLength       STRING      -- short, medium, long
formality            STRING      -- formal, friendly, casual
```

### CompanionConversation
```sql
id                 UUID
elderId            UUID
userMessage        STRING
companionResponse  STRING
sentiment          STRING?     -- POSITIVE, NEUTRAL, NEGATIVE, CONCERNED
actionTriggered    JSON?       -- Any actions taken
timestamp          TIMESTAMP
```

### CompanionReminder
```sql
elderId       UUID
reminderType  STRING         -- MEDICATION, APPOINTMENT, EXERCISE, CHECK_IN
title         STRING
message       STRING
scheduledFor  TIMESTAMP
delivered     BOOLEAN
acknowledged  BOOLEAN
```

### CompanionActivity
```sql
elderId      UUID
activityType STRING          -- CONVERSATION, REMINDER, EXERCISE, CALL
description  STRING
mood         STRING?         -- Assessed mood during activity
duration     INT?            -- Duration in seconds
timestamp    TIMESTAMP
```

## Setup Instructions

### 1. Install Dependencies

```bash
cd backend
npm install axios
```

### 2. Configure OpenAI API

**Get API Key:**
1. Go to https://platform.openai.com
2. Sign up or login
3. Navigate to API Keys
4. Create new secret key
5. Copy the key

**Add to .env:**
```bash
OPENAI_API_KEY=sk-your-actual-openai-api-key-here
```

**Alternative: Claude API**
```bash
# Use Anthropic Claude instead of OpenAI
ANTHROPIC_API_KEY=sk-ant-your-claude-key-here
```

### 3. Run Database Migration

```bash
cd backend
npx prisma migrate dev --name add_ai_companion
npx prisma generate
```

### 4. Start Services

```bash
# Backend
cd backend && npm run dev

# Frontend
cd client && npm run dev
```

### 5. Access Companion

**Add to any page:**
```jsx
import AICompanionChat from './components/companion/AICompanionChat';

<AICompanionChat elderId="elder-123" />
```

**Or create dedicated page:**
```
/companion/:elderId
```

## Use Cases

### Case 1: Daily Check-In (Martha, 82)

**8:00 AM:**
- **Emma:** "Good morning, Martha! Did you sleep well?"
- **Martha:** "Yes, pretty good"
- **Emma:** "That's wonderful! It's time for your morning medications - your Atenolol and baby aspirin. Would you like me to list them?"
- **Martha:** "Yes please"
- **Emma:** "Take your Atenolol 25mg with water, and one baby aspirin 81mg. Let me know when you've taken them!"

**Later:**
- **Martha:** "I took my medicine"
- **Emma:** "Excellent job, Martha! You're doing great. How about some breakfast? And maybe a short walk later this morning?"

### Case 2: Loneliness Support (Robert, 76)

**2:00 PM:**
- **Robert:** "I'm feeling lonely today"
- **Emma:** "I'm sorry you're feeling lonely, Robert. I'm here with you. Would you like to chat for a while? Or maybe we could call your daughter - I know she always loves hearing from you."
- **Robert:** "I miss my wife"
- **Emma:** "I understand, Robert. Missing someone we love is so hard. Your wife was very special. Would it help to share some memories of her with me? I'm here to listen."
- **Robert:** "She loved gardening"
- **Emma:** "How beautiful. Gardening brings so much joy. Do you still have her garden? Maybe we could plan some time outside to enjoy it and remember her. The fresh air might feel good too."

### Case 3: Medication Confusion (Eleanor, 89)

**11:00 AM:**
- **Eleanor:** "Did I already take my blood pressure pill today?"
- **Emma:** "Let me check for you, Eleanor. Yes, you took your Lisinopril this morning at 8:30am. You're all set until your evening dose at 6pm. You're doing a great job keeping track!"
- **Eleanor:** "Oh good, I couldn't remember"
- **Emma:** "That's exactly why I'm here - to help you remember! Don't worry about it. Is there anything else I can help you with?"

### Case 4: Exercise Motivation (Frank, 84)

**3:00 PM:**
- **Emma:** "Hi Frank! The weather is nice today. How about a short walk? Just 10 minutes around the block?"
- **Frank:** "I'm tired"
- **Emma:** "I understand you're tired, Frank. Even a 5-minute walk can help you feel more energized. We could take it very slow. Or if you prefer, how about some gentle seated exercises? I can guide you through them."
- **Frank:** "Maybe the seated ones"
- **Emma:** "Perfect! Let's start easy. Sit comfortably in your chair. First, let's do some arm circles - raise your arms to shoulder height and make small circles. Do 10 forward, then 10 backward. I'll wait while you do them."

### Case 5: Appointment Reminder (Grace, 87)

**9:00 AM (Day before appointment):**
- **Emma:** "Good morning, Grace! Just a reminder - you have a cardiology appointment tomorrow at 2pm with Dr. Johnson. It's at the Heart Center on Main Street."
- **Grace:** "Oh, I almost forgot! What should I bring?"
- **Emma:** "Great question! Bring your insurance card, a list of current medications (I can help you with that), and any questions you have for the doctor. Would you like me to help you prepare?"

**1:00 PM (Day of):**
- **Emma:** "Hi Grace! Your cardiology appointment is in 1 hour. Do you need a ride? Should we call your son?"

## Troubleshooting

### AI Not Responding

**Check:**
1. OPENAI_API_KEY is set correctly in .env
2. API key is valid (not expired)
3. Internet connection is working
4. Backend server is running
5. Check backend logs for errors

**Fallback:**
- If API unavailable, uses rule-based responses
- Basic functionality maintained
- Medication/appointment reminders still work

### Conversations Not Saving

**Check:**
1. Database connection working
2. CompanionConversation table exists
3. elderId is correct
4. Check Prisma client is generated

### Voice Not Working

**Browser Compatibility:**
- Chrome: ✅ Full support
- Edge: ✅ Full support
- Safari: ✅ Supported
- Firefox: ⚠️ Limited support

**Fix:**
- Check browser supports Speech Synthesis
- Unmute device
- Check volume settings
- Toggle voice off/on
